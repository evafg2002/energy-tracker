# Energy Tracker

Energy Tracker is a simple Python project developed during Lab 2 to calculate electricity consumption and estimate its cost.

## How to run

Run the Python script using the following command:

```bash
python energy.py
```

## Features

- Calculate electricity consumption in kWh.
- Estimate electricity costs in euros using a default price of 0.35 EUR/kWh.
